⚠️ Lưu ý về CORS

Website này sử dụng CORS proxy để lấy dữ liệu từ server. Nếu gặp lỗi CORS, bạn có thể:

  • Thử refresh trang - Các proxy khác nhau có thể hoạt động
  • Sử dụng dữ liệu mẫu - Website sẽ tự động chuyển sang dữ liệu demo
  • Chạy local server - Mở file qua localhost thay vì file://

Giải pháp kỹ thuật:

  1. Deploy lên server có hỗ trợ CORS
  2. Sử dụng backend proxy
  3. Cấu hình CORS headers trên server nguồn
